# Keyboard Shortcuts

[← Documentation home](README.md)

Click **Shortcuts** in the toolbar to see this list inside the app.

## Tools

| Key | Action |
|---|---|
| <kbd>B</kbd> | Bounding box |
| <kbd>P</kbd> | Polygon |
| <kbd>V</kbd> | Select / edit |
| <kbd>Space</kbd> | Pan (hold) |
| <kbd>R</kbd> | Repeat last class |
| <kbd>N</kbd> | Mark image as null |
| <kbd>C</kbd> | Change class of the selected box |

## Navigate & view

| Key | Action |
|---|---|
| <kbd>D</kbd> / <kbd>→</kbd> | Next image |
| <kbd>A</kbd> / <kbd>←</kbd> | Previous image |
| <kbd>Shift</kbd>+<kbd>→</kbd> / <kbd>←</kbd> | Next / previous page |
| <kbd>+</kbd> / <kbd>-</kbd> | Zoom in / out |
| <kbd>F</kbd> / <kbd>0</kbd> | Fit to screen |
| <kbd>L</kbd> | Lock zoom |
| <kbd>G</kbd> | Grid |
| <kbd>T</kbd> | Show / hide labels |

## Edit & review

| Key | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Undo / redo |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>V</kbd> | Copy / paste box |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> / <kbd>S</kbd> | Save now |
| <kbd>Delete</kbd> | Delete a box / reject a suggestion |
| <kbd>Enter</kbd> | Accept the selected suggestion · close a polygon |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Accept all suggestions on the image |
| <kbd>Shift</kbd>+<kbd>Delete</kbd> | Reject all suggestions on the image |
| <kbd>Esc</kbd> | Cancel / close popup |

## Class popup

| Key | Action |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move through classes |
| <kbd>Enter</kbd> | Apply the highlighted class |
| Type | Search classes |
| <kbd>Esc</kbd> | Cancel the new box |
